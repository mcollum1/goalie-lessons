Patterns Applied

Each screen section maps to a research pattern. Annotations appear inline on the right side of the device.

P1 · Session Type Cards Gate calendar behind session selection. Price visible before any date interaction. (Acuity, CoachNow)
P2 · Month + Day on One Screen Calendar and time slots visible simultaneously, no page reload. (Calendly)
P3 · Persistent Context Panel Coach photo, price, location always visible — never scroll to find them. (Calendly, Acuity)
P4 · Zero-Account Guest Booking No sign-up required to see or book availability. (Calendly core principle)
P5 · Inline Price Transparency Price visible at 3 checkpoints before payment. (Acuity, Calendly Payments)
P6 · Scarcity Nudges "Only 2 slots left" when genuinely true. Never manufactured. (Mindbody, ClassPass)
P7 · Confirmation as Retention Post-booking screen does 4 jobs: celebrate, calendar add, account offer, upsell. (Acuity 2025)

Design System Notes

✓ Using existing tokens
All colors from tokens.css
Navy panel uses --color-navy. Action blue uses --color-action. Surfaces, borders, and text scale are all from the shared token file.
✓ Using existing tokens
Typography unchanged
Inter at existing scale: --text-title for section heads, --text-sm for meta, --text-caption for badges. No new type ramp needed.
🆕 New component needed
Session Type Card
A horizontally-scrollable card with name, price, duration, and a selected state. Not in current component set. Extends .gc-card with a selection ring using --color-action.
🆕 New component needed
Calendar Grid
7-col day grid with 3 slot states: available (green dot), limited (amber dot), blocked (gray). Selected day uses navy fill + white text. Needs its own component — nothing like this exists in current system.
🆕 New component needed
Time Slot Picker
3-col grid of pill buttons with time + AM/PM. Selected state mirrors session card selection ring. New, but reuses selection pattern from session card.
🆕 New component needed
Coach Context Panel
Navy header with avatar, name, and meta pills. "Meta pill" pattern (semi-transparent background, icon + label) is new. Structurally similar to existing top-header but with brand-color override.
⚠️ Token gap
Green tint missing
--color-green exists but no --color-green-tint is defined in tokens.css. Confirmation screen needs it for the success icon background. Proposed: #E6F7F1. Add to tokens.css.
⚠️ Token gap
Amber / warning palette
Only --status-warning: #b54708 exists in index.html (not in tokens.css). Scarcity nudge needs amber + amber-tint. Proposed: add --color-amber: #F59E0B and --color-amber-tint: #FEF3C7 to tokens.css.
📐 Responsive note
Desktop layout
On ≥768px, the coach panel (P3) moves to a fixed left sidebar, and the calendar + slots panels use a 2-column layout (calendar left, slots right) — the Calendly pattern. Mobile layout shown here is the primary design surface.
